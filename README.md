# Z-Config

Ancienne infrastructure de configuration, initialement conçue pour centraliser et gérer les différents environnements et paramètres de l'infrastructure.

Le projet devait regrouper :
- les configurations globales
- la configuration locale
- les environnements dev, preprod et prod
- la configuration réseau et infrastructure
- les paramètres communs liés au déploiement et à l'exploitation

Le projet avait été abandonné, puis l'idée était de le relancer en local afin de reprendre et moderniser son système de configuration sans dépendre directement de l'ancienne infrastructure
